## Implementation Approach

All seven rules are added as bullet points in the existing "Hard cases" section of `STRUCTURE_PROMPT`. Each rule follows the existing pattern: a signal description → type/group assignment.

**Rule ordering within "Hard cases"**: new rules insert after the existing `.log/.out` rule (they are related) and before the `.html` rule. The pretest rule inserts adjacent to the existing `pilot` rule in the GROUP section.

### Rules to add

1. **Experiment `.log` files without participant ID** — extend the existing `.log` rule:  
   Add folder-context signal: if the `.log` file is inside a folder named `data`, `raw`, or the task name, classify as `data` even without a participant ID in the filename.

2. **Intermediate tabular results** — add after the "tabular files with graph/figure/plot → output" rule:  
   Tabular files (`.csv`, `.sav`, `.dta`, `.xlsx`, `.tsv`, `.dat`) whose names contain `scores`, `processed`, or `cleaned` → `data`, NOT `output`.

3. **Pretest group labelling** — add adjacent to the `pilot` group rule:  
   `pretest` in folder or filename does NOT indicate a pilot. A pretest is a separate study phase → assign `ex<N>` if a study number is present, otherwise `shared`. Never `pilot<N>`.

4. **Prior-study / borrowed data** — add in the data vs supplemental section:  
   Tabular files whose name contains `prior`, `replication`, a 4-digit year adjacent to a study keyword, or `comparison_data` → `data`, not `supplemental`.

5. **Placeholder files** → `other`:  
   Files whose name starts with or contains `example_`, `dummy`, `placeholder` → `other`. Exception: compound names where the word is part of a research construct (e.g., `implicit_association_test` — do not trigger on `test` alone).

6. **Config file taxonomy**:  
   `.yaml`, `.cfg`, `.ini`, `.toml` in an experiment-associated folder (`task/`, `paradigm/`, `experiment/`, `stimuli/`) → `software`. Root-level tooling config (`.eslintrc`, `pyproject.toml`, `Makefile`) → `other`. Analysis config (name contains `analysis`, `model`, `params`) → `code`.

7. **SQL → data**:  
   `.sql` files → `data` (database export/dump). Exception: name contains `query`, `script`, or `procedure` → `code`.
